# Buscador de CEP

Aplicação web estática e leve para consulta de CEPs brasileiros, desenvolvida com HTML, CSS e JavaScript puro. Consome a API pública do ViaCEP para retornar informações completas de endereço em tempo real.

## Funcionalidades

- Consulta de CEP via API ViaCEP
- Máscara automática de entrada (formato 00000-000)
- Estado de carregamento durante a requisição
- Botão de limpar para nova consulta
- Exibição formatada dos dados retornados
- Layout responsivo para dispositivos móveis
- Acessibilidade melhorada com ARIA labels

## Tecnologias

- HTML5
- CSS3
- JavaScript ES6+
- [ViaCEP API](https://viacep.com.br/)

## Como usar

1. Clone o repositório
2. Abra o arquivo `index.html` em seu navegador
3. Digite um CEP válido de 8 dígitos
4. Clique em "Consultar" ou pressione Enter

Ou acesse diretamente a versão hospedada.
